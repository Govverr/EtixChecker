## ✅ Завершено в текущей сессии (Session Wrap-Up)

- [x] **Разрешение конфликта налоговых схем («Empty Shopping Cart»)**
  - Автоматическое распознавание ошибки *«You requested venue has different tax scheme with the venue in cart»*.
  - Автоклик ссылки «Empty Shopping Cart» с подтверждением JS-диалогов и возвратом на целевое шоу.
- [x] **Исправление ложного «0/16 билетов набрано» при добавлении в корзину**
  - Исключение раннего прерывания по информационным баннерам `div[role='alert']`.
  - Увеличение динамического таймаута ожидания корзины до 15.0 с.
  - Расширение селекторов распознавания страницы корзины (`Clear Shopping Cart`, `Empty Shopping Cart`, `Checkout`).
  - Гарантированная очистка корзин (Defense-in-depth) даже при `total_reserved == 0`, если воркер находится на странице корзины.
- [x] **Каскад решения Google reCAPTCHA v2 / Enterprise & клик по «человечку»**
  - Поддержка нативной кнопки Google Liveness Challenge (`#recaptcha-liveness-button`, `.rc-button-liveness`) и расширения Buster (`#solver-button` в Shadow DOM).
  - Динамический fallback-сканер тулбара диалога капчи.
  - Внутридиалоговый цикл повторных попыток (`max_attempts = 3`): Reload ('↺') $\to$ «человечек» $\to$ 10 с ожидания.
  - Мгновенный Fast-Abort при блокировке Google DOSCaptcha (`.rc-doscaptcha-body`).
- [x] **Поддержка Google reCAPTCHA Enterprise и адаптивных габаритов**
  - Устранено ошибочное условие `bounding_box.width > 350px`, приводившее к игнорированию капчи в компактных окнах ($749 \times 514\text{ px}$).
  - Внедрено обнаружение фреймов `enterprise/bframe` и сквозное сканирование `page.frames`.
  - Post-solve форма: автоматический повторный клик «Add Tickets» с готовым токеном `g-recaptcha-response`, если авторедирект не сработал.
- [x] **Защита от зависания окон на рабочем столе (Anti-Hanging Window)**
  - Прямая проверка состояния страницы (`is_recaptcha_challenge_visible`, слайдер, блокировка) при любой ошибке добавления в корзину.
  - Гарантированное принудительное закрытие сбойного браузера через AdsPower Local API и Hot-Swap из резерва группы `Inventory Etix (DO NOT TOUCH)`.
- [x] **Автоматическое восстановление при ошибке SYS-BS-004**
  - Перехват ошибки *«Response to CAPTCHA is required. Please go back and try again. Status Code: SYS-BS-004»*.
  - Нажатие кнопки «Back», повторный выбор билетов, решение капчи и повторный переход в корзину.
- [x] **Стабильная контрольная точка и слияние с `main`**
  - В `PROJECT_KNOWLEDGE.md` зафиксирован коммит `c08bb48` как проверенная рабочая версия ветки `main`.
  - Ветка `fix/recaptcha-retry-flow` успешно влита в `main` (Fast-forward, коммит `9bf83a4`).
  - Все 61 модульный тест пройдены на 100% (GREEN). Ветка готова к ручному пушу пользователем.

## ⏳ Планы на следующий чат (Upcoming Tasks)

- [ ] **Решение проблемы со слайдер-капчей DataDome при добавлении билетов в корзину**
  - *Контекст:* В момент нажатия «Add Tickets» появляется слайдер-капча DataDome. Сейчас она временно устраняется перезапуском страницы.
  - *Задача:* Разработать надежную стратегию: решение слайдера «на месте» с сохранением выбранного количества или умный релоад с повторным выбором билетов без потери сессии.
- [ ] **Решение проблемы со слайдер-капчей DataDome при очистке корзины**
  - *Контекст:* В момент очистки корзины (`clear_cart` / «Clear Shopping Cart») также стала появляться слайдер-капча. Если выполнить перезагрузку страницы, Etix возвращает пользователя обратно в корзину, в которой билеты остаются неудаленными.
  - *Идея пользователя:* Добавить очистку куки (`page.context().clear_cookies()`) при появлении капчи во время очистки корзины, с последующим переходом на новое шоу.
  - *Задача:* Проанализировать и согласовать варианты решения:
    1. Очистка куки (`datadome`, сессионные куки) через CDP/Playwright + навигация на следующее шоу.
    2. Попытка нативного решения слайдера прямо на странице корзины.
    3. Принудительный сброс корзины через вызов URL очистки / Hot-Swap воркера, если капча не уходит.
- [ ] **Поиск и интеграция полигона / тестового стенда для слайдер-капчи DataDome**
  - *Задача:* Найти публичный или тестовый сайт (по аналогии с `https://www.google.com/recaptcha/api2/demo` для Google reCAPTCHA), где стабильно воспроизводится слайдер-капча DataDome.
  - *Обучение и калибровка:* Протестировать и обучить чекер правильно сдвигать ползунок DataDome (биометрическая траектория Безье, дотягивание до правого края трека, джиттер).
  - *Интеграция:* Встроить откалиброванный алгоритм решения слайдера в чекер на этапах входа на шоу, добавления в корзину и очистки корзины.
