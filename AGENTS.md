## 🏗️ 4. Главные инварианты и архитектурные решения
1. **AdsPower Local API (порт 50325):**
   - Управление браузерами SunBrowser через REST API (`http://127.0.0.1:50325`).
   - Все профили должны браться **СТРОГО** из группы:
     ```text
     Inventory Etix (DO NOT TOUCH)
     ```
   - В группе может быть любое количество профилей (12, 50, 100+). Пул динамический.
2. **Случайный выбор профилей (Random Sampling):**
   - Для проверки события, требующего $N$ профилей, чекер **всегда** выбирает $N$ профилей случайным образом (`random.sample`) из группы `Inventory Etix (DO NOT TOUCH)` для равномерного расхода прокси.
3. **Hot-Swap замена профилей:**
   - При сбое прокси или блокировке замена упавшего профиля выбирается **только** из доступных свободных профилей группы `Inventory Etix (DO NOT TOUCH)`.
4. **Проверка занятости профилей (Multi-user concurrency):**
   - Если профиль уже открыт другим пользователем или процессом в AdsPower, он считается занятым. При нехватке свободных профилей чекер должен предупредить пользователя и не начинать проверку.
5. **Playwright CDP:**
   - Подключение через `connect_over_cdp` к `ws://` эндпоинту AdsPower.
   - Строгая санитария вкладок (`bring_to_front()`, закрытие лишних вкладок `start.adspower.net`).
6. **1-based `ticket_index`:**
   - В `shows.csv` параметр `ticket_index = 1` означает первый селектор билетов сверху, `ticket_index = 2` — второй.
7. **Поддержка селекторов Material-UI и HTML Select:**
   - Поддерживаются как классические `<select>`, так и Material-UI v5 (`div[role="combobox"]`, `.MuiSelect-select`). Исключаются тарифные селекторы (*Best Available*).
8. **Staggered Human-Paced Pipeline:**
   - Все действия распределены случайными человеческими задержками (джиттером) в пределах безопасных порогов `MIN_SAFE_DELAYS`.
9. **3-этапная защита DataDome:**
   - (1) Слайдер по кривой Безье с естественным дрожанием мыши ($Y \pm 1-3\text{px}$), полным дотягиванием до правого края и верификацией куки $\rightarrow$
   - (2) Сброс куки сессии и чистая вкладка $\rightarrow$
   - (3) Hot-Swap замена на чистый профиль из группы `Inventory Etix (DO NOT TOUCH)`.
10. **Защита пользовательских файлов:**
    - При любых обновлениях и операциях файлы `.env`, `data/shows.csv`, `data/good_proxies.txt`, `data/bad_proxies.txt`, `data/adspower_backup/` и `runs/` остаются нетронутыми.
