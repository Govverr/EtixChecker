# 🎟️ Etix Checker 2026 — AdsPower CDP Edition

Высокопроизводительный асинхронный чекер доступности и инвентаря билетов на платформе **Etix**, работающий на базе антидетект-браузеров **AdsPower Local API** через протокол **Playwright CDP (Chrome DevTools Protocol)**.

---

## 🌟 Ключевые возможности

* 🚀 **AdsPower CDP Engine:** Управление пулом изолированных браузерных профилей SunBrowser с уникальными цифровыми отпечатками железа и выделенными резидентскими/мобильными прокси через прямой Chrome DevTools Protocol (`connect_over_cdp`).
* ⚡ **Автоматический установщик (One-Click Installer):** Развертывание всего проекта, Python 3.11, виртуального окружения `venv`, Playwright Chromium и ярлыка на рабочем столе за один клик через `setup_installer.bat`.
* 🎨 **Современный Dark Dashboard GUI:** Стильный темный интерфейс в эстетике Slate-Navy & Indigo на базе `CustomTkinter` с живыми метриками, динамическими карточками событий, прогресс-барами и журналом событий.
* 👥 **Многопользовательская изоляция (Multi-User Concurrency):**
  - Перед стартом чекер опрашивает `/api/v1/browser/active` и выявляет профили, уже открытые коллегами или другими задачами.
  - Занятые профили помечаются `BUSY_EXTERNAL` и исключаются из выборки.
  - Если свободных профилей меньше необходимого максимума, старт блокируется с понятным предупреждением.
  - При закрытии останавливаются **строго** профили текущей сессии.
* 🎲 **Динамический пул и случайная выборка (Random Sampling):**
  - Профили берутся из группы AdsPower `Inventory Etix (DO NOT TOUCH)` с динамическим размером (12, 30, 80+ профилей).
  - Для проверки события чекер выбирает нужное число профилей ($\lceil\text{target\_total} / \text{max\_per\_order}\rceil$) строго методом `random.sample` для равномерного расхода трафика прокси.
* 🛡️ **Защита DataDome и строгий протокол восстановления:**
  1. **Плавный слайдер по кривой Безье:** Протягивание ползунка с естественным дрожанием мыши ($Y \pm 1-3\text{px}$) и гарантированным аппаратным упором в правый край трека.
  2. **1 попытка перезагрузки (Cookie Reset):** При обнаружении блокировки («Access Temporarily Blocked») или нерешенного слайдера чекер сбрасывает куки и выполняет **ровно 1 перезагрузку**.
  3. **Чистое закрытие и Hot-Swap (до 3 замен):** Если профиль все еще заблокирован, его браузер немедленно закрывается (`browser.close()` и `stop_browser()`), а чекер открывает чистый профиль из группы `Inventory Etix (DO NOT TOUCH)` с заменой прокси. На каждый слот выделяется **до 3 замен**.
  4. **Автономное продолжение:** При исчерпании 3 замен сбойный браузер чисто закрывается, а чекер продолжает резервирование оставшимися подтвержденными воркерами (например, 3 из 4).
* 🚫 **Аудит заблокированных профилей и уведомления для ротации:**
  - Все заблокированные профили автоматически логируются в `data/blocked_profiles.txt` (дата, имя, user_id, прокси, причина).
  - В верхней панели GUI добавлена кнопка быстрого доступа: `🚫 Заблокированные` (открытие файла в 1 клик).
  - По окончании проверки при наличии блокировок выводится предупреждающее модальное окно и таблица в CLI с рекомендацией сменить прокси или цифровой отпечаток.
* 🎯 **Инвентарная защита и исключение ложных Sold Out:**
  - Исключены ложные срабатывания Sold Out из-за совпадений в биографиях артистов.
  - Поддержка статуса «Off Sale Online» и листа ожидания («Set Alert»).
  - Инвентарный предохранитель (`has_active_ticket_controls`): если селекторы билетов доступны на странице, событие ни при каких условиях не объявляется Sold Out или Ended.
* 🧩 **Поддержка Material-UI v5 и HTML Select:** Безошибочное распознавание селекторов количества билетов (как в Material-UI `[role="combobox"]`, так и в классических `<select>`) с автоматическим исключением тарифных списков (*Best Available*).
* ⚙️ **Вкладка настройки задержек в GUI («⚙️ Настройки задержек»):**
  - Настройка интервалов навигации, кликов, добавления в корзину и удержания.
  - Аппаратная валидация порогов безопасности `MIN_SAFE_DELAYS`.
  - Кнопки сохранения в `.env` и сброса по умолчанию, живой калькулятор времени проверки шоу.
* 🛒 **Мгновенная очистка корзин (`Clear Shopping Cart`):** Автоматическое освобождение зарезервированного инвентаря после заданной паузы удержания (по умолчанию 4 сек).
* 💾 **Отказоустойчивые чекпоинты (`checkpoint.json`):** Возможность прервать проверку в любой момент и возобновить с последнего незавершенного шоу.
* 🔄 **Обновление в 1 клик (1-Click Updater):** Проверка наличия новых версий на GitHub и обновление в 1 клик без перезаписи `.env`, `data/shows.csv` и прокси.
* 📖 **Подробное руководство пользователя:** Файл [`ИНСТРУКЦИЯ.md`](ИНСТРУКЦИЯ.md) с пошаговыми инструкциями.

## ⚡ Быстрый старт (One-Click)

### 1. Автоматическая установка
Просто запустите файл **`setup_installer.bat`** двойным кликом. Он выполнит все настройки:
* Проверит/установит Python 3.11.
* Создаст изолированное окружение `venv` и установит все зависимости.
* Установит браузер Playwright Chromium в локальный кэш `ms-playwright/`.
* Создаст файл конфигурации `.env`.
* Создаст ярлык **«Etix Checker 2026»** на рабочем столе.

### 2. Подготовка AdsPower
1. Запустите десктопный клиент **AdsPower**.
2. Включите **Local API** на порту **50325** (по умолчанию `http://127.0.0.1:50325`).
3. Создайте группу с названием:
   ```text
   Inventory Etix (DO NOT TOUCH)
   ```
4. Добавьте в эту группу ваши браузерные профили с прокси (рекомендуется от 12 до 50+ шт.).

### 3. Заполнение `data/shows.csv`
Укажите ссылки на события в файле `data/shows.csv` (можно открыть прямо из GUI по кнопке **`📄 shows.csv`**):
```csv
name,url,target_total,max_per_order,ticket_index
NateSmith,https://www.etix.com/ticket/p/35196855/nate-smith-palmer-alaska-state-fair,12,4,2
Gasolina Party,https://www.etix.com/ticket/p/87677793/gasolina-party-providence-the-strand-theatre?partner_id=100,24,6,2
```
* **`name`**: Понятное название события (без запятых).
* **`url`**: Полная ссылка на страницу покупки билетов Etix.
* **`target_total`**: Общая цель по билетам (суммарно по всем профилям).
* **`max_per_order`**: Лимит на один заказ/профиль (например, 4 или 6).
* **`ticket_index`**: Номер селектора билетов сверху (1-based: `1` — первый сверху, `2` — второй сверху).

### 4. Запуск проверки
* Через ярлык на рабочем столе **«Etix Checker 2026»**.
* Либо через файл **`run_gui.bat`** (или `run_gui.vbs` без консольного окна).
* Либо в консольном режиме через **`run.bat`** (`cli.py`).

## 📊 Результаты проверки (`report.csv`)

По завершении проверки создается итоговый отчет `report.csv`:
```csv
name,status,target,reserved,available_approx,details,notes
Gasolina Party,OK,24,24,24,Успешно зарезервировано 24/24 (4/4 корзин),
```

### Статусы событий:
| Статус | Цвет | Описание |
| :--- | :--- | :--- |
| **`OK`** | 🟢 Зеленый | Мероприятие полностью доступно. Цель по билетам набрана на 100% во всех корзинах. |
| **`ЧАСТИЧНО`** | 🟡 Желтый | Набрана только часть билетов (например, 18/24, 3/4 корзин). Указано точное число. |
| **`SOLD OUT`** | 🔴 Красный | Билеты распроданы (подтверждено отсутствием активных селекторов инвентаря). |
| **`SALES ENDED`** | ⚪ Серый | Продажи официально завершены организатором. |
| **`BLOCKED`** | 🟣 Фиолетовый | Блокировка DataDome (после 1 перезагрузки и всех попыток Hot-Swap). |
| **`FAILED`** | 🔴 Бордовый | Ошибка сети или недоступность страницы. |

## 🧪 Тестирование и верификация

Для запуска полного набора модульных тестов:
```powershell
.\venv\Scripts\python.exe -m unittest discover tests
```

Набор тестов верифицирует:
- Извлечение `performance_id` и парсинг URL.
- Аппаратное ограничение задержек `MIN_SAFE_DELAYS`.
- Детекцию многопользовательской занятости профилей AdsPower (`BUSY_EXTERNAL`).
- Случайную выборку и Hot-Swap внутри группы `Inventory Etix (DO NOT TOUCH)`.
- Исключение ложного Sold Out (биографии артистов, Off Sale Online, листы ожидания).
- Инвентарную защиту (`has_active_ticket_controls`).
- Отслеживание, дедупликацию и сохранение заблокированных профилей.
- Протокол «1 перезагрузка $\rightarrow$ закрытие $\rightarrow$ Hot-Swap» и лимит до 3 замен.
- Безопасное удаление воркеров через `stop_and_remove_worker`.
